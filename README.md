## 🧪 Testing & Quality Engineering background

Before focusing fully on backend development, I spent nearly 3 years deep in software quality — and that experience still shapes how I write code today. Tools and practices I've worked with:

- **UI & E2E automation:** Playwright, FlaUI (Windows/WinForms desktop apps), Appium
- **Test frameworks:** NUnit, Robot Framework
- **API testing & performance:** Postman, K6
- **Process:** Azure DevOps Test Plans, exploratory testing, structured test case design, Go/No-Go release checklists

The result: I don't just write features, I write features that are built to survive contact with real users.

## 🏠 Home Lab

A small self-hosted setup I maintain in my free time:

- 🐧 **Ubuntu Server** as the backbone, running everything through Docker
- 🔒 **Tailscale** for a private mesh VPN across all my devices, no matter where I am
- 🚫 **Pi-hole** for network-wide DNS-based ad blocking
- 🌐 Worked around a locked-down ISP router (bridge mode, routing quirks and all) to get everything talking to each other properly

It's basically my personal playground for infra, networking, and "let's see if I can make this work" problem solving.
